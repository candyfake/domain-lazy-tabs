# 验证记录

2026-09-24，在独立临时配置目录中使用 Chrome for Testing 151.0.7922.34（Chromium）验证，未修改用户的个人浏览器配置。

- 19 项 Node 逻辑测试通过：域名边界、安全 URL、同步右键改写与恢复、Alt 绕过、配置切换、前后台激活竞态等。
- 实际浏览器可信右键事件处理时，目标链接已同步变为本地占位 URL，随后 DOM 中的原链接恢复。
- 用右键事件捕获的同一 URL 创建后台标签页，等待 2 秒，测试服务器目标请求数为 **0**；激活后收到 **1** 次请求。
- 实际 Ctrl 点击与中键打开后台页时，目标请求数不增加。
- 连续中键打开 **10** 个受管后台页，目标请求数仍不增加。
- 未受管域名照常加载；普通左键照常导航；Alt 右键保留原链接；查询参数、中文和 URL 片段保留。

边界：自动化采用无头 Chromium，不能点击操作系统的原生右键菜单条目。测试验证了可信右键事件中的 URL，以及用该 URL 打开后台页后的网络行为；不能把它说成完整的操作系统菜单点击实测。尚未在登录态 Linux.do 上验证所有主题、站点脚本和其他扩展组合。

复现命令见 README。`tests/browser.cjs` 使用本机 HTTP 服务器统计 `/target` 请求，不依赖目标站点响应，也不拿页面外观推断“零请求”。运行输出保存到被 Git 忽略的 `artifacts/`。
